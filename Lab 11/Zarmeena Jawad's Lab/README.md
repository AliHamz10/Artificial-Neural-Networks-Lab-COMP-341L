# Lab 11 - Zarmeena Jawad

## Included Files
- `lab11_lstm_timeseries_forecasting_colab.ipynb`: Google Colab notebook for Lab 11
- `build_lab11_lstm_timeseries_notebook.py`: script used to generate the notebook

## Dataset
The notebook supports any univariate time-series CSV (sales / demand / etc.).  
Default filename inside the notebook:
- `Sales Forecasting Dataset.csv`

If the CSV is missing in the lab folder, the notebook downloads a small public monthly time-series dataset automatically so you can run the full workflow.

## How to run in Colab
1. Open `lab11_lstm_timeseries_forecasting_colab.ipynb` in Google Colab.
2. Keep Google Drive enabled in the setup cell.
3. Run all cells in order.
4. Outputs will be written to:
   - `/content/drive/MyDrive/COMP-341L/Lab 11/Zarmeena Jawad's Lab`
5. It saves figures to `plots/` and exports:
   - `Lab_Report_11.md`
   - `Lab_Report_11.html`

## Google Drive note
This notebook is configured to save **everything** (dataset copy, plots, and reports) into the Google Drive lab folder. If the Drive mount fails, rerun the first setup cell.
