1. Objective

The goal of this lab was to study model generalization in image classification. The work started with a simple CNN to diagnose overfitting, then moved to parameter tuning, pretrained feature extraction, and controlled fine-tuning to examine how each design choice affects validation and test performance.

Key finding: the strongest results came from transfer learning. The baseline CNN overfit heavily, the modified CNN performed worse than expected, and MobileNetV2 produced the best overall generalization.

2. Dataset and Setup

The lab manual allows the use of a CIFAR-10 subset or a custom waste dataset. For a reproducible Colab workflow, a three-class CIFAR-10 subset was used as a proxy:

airplane -> Plastic automobile -> Paper ship -> Metal

Images were split into training, validation, and test sets. The standard CNN pipeline used normalized 32x32 inputs, while the transfer-learning pipeline resized images to 96x96 and applied mobilenet_v2.preprocess_input.

Important Code: Data Pipeline

def preprocess_for_cnn(images, labels):
    images = tf.cast(images, tf.float32) / 255.0
    labels = tf.cast(labels, tf.int32)
    return images, labels

def preprocess_for_transfer(images, labels):
    images = tf.cast(images, tf.float32)
    images = tf.image.resize(images, TRANSFER_IMG_SIZE)
    images = tf.keras.applications.mobilenet_v2.preprocess_input(images)
    labels = tf.cast(labels, tf.int32)
    return images, labels

def make_dataset(x, y, preprocess_fn, training=False):
    ds = tf.data.Dataset.from_tensor_slices((x, y))
    if training:
        ds = ds.shuffle(len(x), seed=SEED)
    ds = ds.map(preprocess_fn, num_parallel_calls=AUTOTUNE)
    ds = ds.batch(BATCH_SIZE).prefetch(AUTOTUNE)
    return ds

3. Task 1: Baseline CNN and Overfitting Diagnosis

The first experiment used the baseline architecture provided in the lab. It was trained for 10 epochs and evaluated through training versus validation accuracy.

Important Code: Baseline Model

def build_baseline_model():

        tf.keras.layers.Conv2D(32, (3, 3), activation="relu", input_shape=(32, 32, 3)),

4. Task 2: Network Parameter Modification

To reduce overfitting, the network was modified with four changes: Batch Normalization, Dropout, fewer dense units, and a smaller Adam learning rate.

Important Code: Modified CNN

def build_modified_model():
    model = tf.keras.Sequential([
        tf.keras.layers.Input(shape=(32, 32, 3)),
        tf.keras.layers.Conv2D(32, (3, 3), padding="same", activation=None),
        tf.keras.layers.BatchNormalization(),
        tf.keras.layers.Activation("relu"),
        tf.keras.layers.MaxPooling2D(2, 2),
        tf.keras.layers.Dropout(0.25),

        tf.keras.layers.Conv2D(64, (3, 3), padding="same", activation=None),
        tf.keras.layers.BatchNormalization(),
        tf.keras.layers.Activation("relu"),
        tf.keras.layers.MaxPooling2D(2, 2),
        tf.keras.layers.Dropout(0.30),

        tf.keras.layers.Flatten(),
        tf.keras.layers.Dense(64, activation="relu"),
        tf.keras.layers.Dropout(0.40),
        tf.keras.layers.Dense(3, activation="softmax"),
    ])

    model.compile(
        optimizer=tf.keras.optimizers.Adam(learning_rate=3e-4),
        loss="sparse_categorical_crossentropy",
        metrics=["accuracy"],
    )
    return model

Did validation improve? No. Validation accuracy changed from 0.8921 to 0.8730, so there was no improvement in this run.

Why reduce the learning rate during fine-tuning? Pretrained weights already contain useful visual features. A small learning rate updates them gradually, which lowers the risk of destroying previously learned representations through overly large optimization steps.

8. Conclusion

This lab clearly showed the progression from a weakly generalizing CNN to a much stronger transfer-learning solution. The baseline CNN overfit, the manually modified CNN did not improve performance, and MobileNetV2 produced the most reliable validation and test results. Fine-tuning did not raise validation accuracy in this particular run, but it still yielded a high final test accuracy of 0.9079. Overall, the experiment highlights that pretrained models often provide a more effective and stable foundation than small CNNs trained from scratch on limited data.
