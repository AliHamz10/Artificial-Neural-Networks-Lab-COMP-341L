Task 2 — Dataset requirements & preprocessing

  • Vocabulary constraint: only the top MAX_FEATURES = 10000 words are used.
  • Tokenization: provided by the dataset (reviews are already integer-encoded).
  • Padding/truncation: sequences are padded to MAX_LEN = 200 with padding="post" and truncating="post".
  • Encoding: labels remain 0/1 for binary cross-entropy.
Code description (Task 2): Padding converts variable-length reviews into a fixed 2D tensor so the network can train in batches. 
from tensorflow.keras.preprocessing.sequence import pad_sequences

(x_train_raw, y_train), (x_test_raw, y_test) = tf.keras.datasets.imdb.load_data(num_words=10000)
x_train = pad_sequences(x_train_raw, maxlen=200, padding="post", truncating="post")
x_test  = pad_sequences(x_test_raw,  maxlen=200, padding="post", truncating="post")

Task 3 — Model development (SimpleRNN)

The model uses an embedding layer to learn dense word representations, followed by a SimpleRNN layer, and a sigmoid classifier for binary sentiment output.

LayerRole
Embedding(10000, 64)Transforms token IDs into 64‑dimensional embeddings.
SimpleRNN(64)Processes the sequence while carrying a hidden state.
Dense(1, sigmoid)Outputs probability of positive sentiment.
Code description (Task 3): The model is compiled with adam optimizer and binary_crossentropy; accuracy is tracked per epoch. 
model = tf.keras.Sequential([
  tf.keras.layers.Embedding(10000, 64, input_length=200),
  tf.keras.layers.SimpleRNN(64),
  tf.keras.layers.Dense(1, activation="sigmoid")
])
model.compile(optimizer="adam", loss="binary_crossentropy", metrics=["accuracy"])
