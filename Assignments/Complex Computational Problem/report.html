Neural Computing System for Handwritten Digit Recognition (MNIST)

Abstract

This project implements a complete neural computing pipeline for recognizing handwritten digits (0–9) from the MNIST dataset, using NumPy-only model implementations (external libraries are used strictly for loading MNIST). We sequentially implement and evaluate four foundational paradigms: (1) a single-layer Perceptron as a baseline binary classifier, (2) an Adaline (Adaptive Linear Neuron) trained by the Delta Rule via gradient descent, (3) a Kohonen Self-Organizing Map (SOM) for unsupervised clustering and topology-preserving feature learning, and (4) a multi-layer perceptron (MLP) trained with Backpropagation for full 10-class digit classification. Experimental outputs include decision boundary evolution for the Perceptron, MSE loss surfaces and learning-rate convergence curves for Adaline, SOM visualizations (U-matrix, prototype maps, class hit maps) and quality metrics (Quantization Error, Topographic Error), anomaly detection using per-sample quantization error, and MLP training/validation curves with activation and regularization comparisons. On our MNIST setup, the final MLP achieved 97.14% test accuracy, while the Perceptron reached 99.34% accuracy on a binary (0 vs 1) PCA-2D visualization task. The SOM produced QE = 5.535 and TE = 0.1078, enabling anomaly detection with precision = 0.8299, recall ≈ 1.0, and F1 = 0.9070 at a 95th-percentile threshold. Overall, the four paradigms form a unified learning system illustrating how linear decision rules evolve into gradient-based multi-layer representations and how unsupervised topological maps can support analysis and auxiliary feature design.

1. Introduction

1.1 Motivation and objectives

Neural computation is inspired by biological neurons and their emergent behavior when organized into networks. Historically, early neural models such as the Perceptron introduced the core idea that a weighted combination of inputs can implement a decision boundary. Over time, limitations of single-layer models motivated differentiable learning rules (e.g., the Delta Rule for Adaline) and, eventually, the generalization to deep, multi-layer networks trained by Backpropagation. Separately, unsupervised paradigms such as Kohonen Self-Organizing Maps (SOMs) provide a different learning lens: they compress high-dimensional structure into a topology-preserving grid that supports clustering, visualization, and anomaly detection.

Objective of this project: Build a comprehensive neural computing system for MNIST digit recognition by implementing four paradigms and comparing them using consistent metrics and visual evidence.

1.2 Dataset: MNIST

MNIST contains 28×28 grayscale images of handwritten digits (0–9). Each image is flattened into a 784-dimensional vector. Inputs are scaled into the range [0, 1]. For the MLP, feature standardization is applied to stabilize gradient-based optimization; this preprocessing is a deterministic transformation and the models remain NumPy-only.

1.3 Paradigms overview

  1. Perceptron (Part A): supervised baseline for binary linear classification.
  2. Adaline + Delta Rule (Part B): supervised linear model trained by MSE gradient descent.
  3. SOM (Part C): unsupervised topology-preserving map for clustering/visualization/anomalies.
  4. Backpropagation MLP (Part D): supervised 10-class MNIST classifier (784→128→64→10).

2. Part A — Perception and the Perceptron Model

2.1 Biological mapping and historical context

The Perceptron is motivated by the biological neuron. A simplified mapping is: dendrites → input features, synapses → weights (synaptic strength), soma → weighted sum + bias, and axon firing → a thresholded, binary output. This conceptual mapping motivates the mathematical structure of the Perceptron and the learning-by-error-correction update rule.

A major limitation of the single-layer Perceptron is that it can represent only linearly separable decision boundaries (a single hyperplane). The XOR problem is a classical counterexample, motivating multi-layer networks with hidden representations.

2.2 Perceptron formulation

net = wᵀx + b
y = 1[net ≥ 0]
w ← w + η(d − y)x    and    b ← b + η(d − y)

Here, x is the input vector, w is the weight vector, b is a bias term, d is the target label, and η is the learning rate.

2.3 Implementation (NumPy only)

Listing A1. Core Perceptron update loop (from src/perceptron.py). 
for _ in range(self.epochs):
    miscls = 0
    for xi, di in zip(xb, y):
        yi = 1 if (xi @ self.w) >= 0 else 0
        err = di - yi
        if err != 0:
            miscls += 1
            self.w = self.w + self.lr * err * xi
    self.history_["miscls"].append(int(miscls))
    self.history_["w"].append(self.w.copy())

2.4 MNIST binary experiment and decision boundary plots

To visualize decision boundaries, MNIST images (784-D) are projected to 2D using PCA. A Perceptron is trained on the PCA-2D representation for digits 0 vs 1, and boundaries are plotted over epochs. The test accuracy for this PCA-2D binary task was 0.99338.

2.5 Convergence analysis: separable vs non-separable

When the dataset is linearly separable, Perceptron updates converge to a separating hyperplane. Empirically, this behavior is demonstrated on a synthetic linearly separable dataset. However, for non-linearly separable problems like XOR, the Perceptron cannot converge to zero error because no single hyperplane exists that separates the classes.

3. Part B — The Delta Rule and Adaline

3.1 Mathematical derivation (from MSE)

Adaline uses a continuous linear output during training, enabling gradient descent. With linear output ŷ = wᵀx + b and mean squared error objective E = (1/2N) Σ(d − ŷ)², differentiating with respect to w yields the Delta Rule update:

Δwᵢ = η(d − ŷ)xᵢ

3.2 Implementation (NumPy only)

Listing B1. Batch gradient descent update for Adaline (from src/adaline.py). 
y_hat = xb @ self.w
err = y - y_hat
grad = -(xb.T @ err) / n
self.w = self.w - self.lr * grad
mse = float((err**2).mean() / 2.0)

3.4 Learning rate analysis

Learning rate controls the step size in gradient descent. Small values are stable but slow; larger values converge faster but can diverge on highly curved objectives. In our experiment (Figure B4), η = 0.1 converged fastest and remained stable, while η = 0.0001 made minimal progress.

4. Part C — Kohonen Self-Organizing Maps (SOM)

4.1 Architecture and competitive learning

A SOM maps high-dimensional inputs to a 2D grid of neurons. Each neuron stores a weight vector (prototype). For an input x, the best matching unit (BMU) minimizes the Euclidean distance to its weight vector. Nearby neurons (in grid coordinates) update together using a Gaussian neighborhood function; both learning rate and neighborhood radius decay over time.

BMU = argminᵢ ‖x − wᵢ‖
wᵢ(t+1) = wᵢ(t) + η(t) · h(BMU, i, t) · (x − wᵢ(t))

4.2 Implementation (NumPy only)

Listing C1. Local neighborhood update (from src/som.py). 
bmu_r, bmu_c = self.bmu(xi)
lr_t, sigma_t = self._decay(t, max_t)
rad = int(np.ceil(3.0 * sigma_t))
h = np.exp(-dist2 / (2.0 * (sigma_t**2 + 1e-12))).astype(np.float32)
self.weights[r0:r1+1, c0:c1+1] = w_local + lr_t * h[..., None] * (xi - w_local)

4.3 Visualization and evaluation

The SOM is evaluated using quantization error (QE) and topographic error (TE). From the main notebook run: QE = 5.535064 and TE = 0.10775.

4.4 Anomaly detection using per-sample quantization error

Anomalies (corrupted or ambiguous digits) tend to be far from the closest SOM prototype. We compute per-sample quantization error and classify a sample as anomalous if its error exceeds a threshold set to the 95th percentile of the clean distribution. In the notebook run, the threshold was 7.481676, yielding precision = 0.829876, recall ≈ 1.0, and F1 = 0.907029.

5. Part D — Backpropagation Networks (MLP)

5.1 Theoretical derivation (error signals and chain rule)

Backpropagation computes gradients efficiently via the chain rule. For a multi-layer network, error signals (“deltas”) propagate from output to hidden layers. With softmax + cross-entropy, the gradient at the logits simplifies to (p − y), improving stability and reducing algebraic complexity in code.

Output delta: δₖ = (dₖ − yₖ) · f′(netₖ)
Hidden delta: δⱼ = f′(netⱼ) · Σₖ δₖ · wₖⱼ
Weight update: Δwᵢⱼ = η · δⱼ · oᵢ
Softmax+CE shortcut: ∂E/∂logits = (p − y)

The MLP is implemented in src/mlp.py with architecture 784 → 128 → 64 → 10. It uses He initialization for ReLU, mini-batch SGD with momentum, and optional L2 weight decay and dropout.

5.3 Results: training curves and confusion matrix

The final model achieved a test accuracy of 0.9714 (97.14%), exceeding the ≥95% target.

5.4 Activation function comparison

Sigmoid and tanh can suffer from vanishing gradients due to saturation; ReLU often converges faster on deep networks. In our comparison, ReLU achieved the highest and fastest validation accuracy, tanh was close, and sigmoid converged slower with a lower final accuracy.

5.5 Regularization (L2 weight decay and dropout)

Regularization constrains model complexity and can reduce overfitting. L2 weight decay penalizes large weights, while dropout reduces co-adaptation by randomly dropping hidden units during training. In our run, regularization increased training loss but reduced the gap between training and validation behavior, indicating less over-optimization on the training set.

5.6 SOM integration (auxiliary features)

To test whether topological preprocessing helps classification, we appended normalized BMU grid coordinates (row, col) as two auxiliary inputs to the MLP. In our run, the baseline final validation accuracy was 0.964833 while the SOM-augmented final validation accuracy was 0.964333. SOM features did not improve final accuracy, although they were slightly better during some early epochs.

6. Comparative Analysis

The four paradigms can be compared in terms of supervision type, objective functions, representational capacity, and computational cost. The table below summarizes the key differences and where each approach is most appropriate.

Paradigm Supervision Objective Strengths Limitations Best use case
Perceptron Supervised Misclassification error Fast, interpretable baseline Requires linear separability Binary linear baseline
Adaline (Delta Rule) Supervised MSE (least squares) Differentiable learning, convex objective Still linear boundary Bridge to backpropagation
SOM (Kohonen) Unsupervised Topology-preserving quantization Clustering, visualization, anomaly detection No direct class objective Feature learning + interpretability
MLP (Backprop) Supervised Cross-entropy Non-linear representations, high accuracy More compute, tuning required Full 10-class digit recognition

For MNIST 10-class recognition, single-layer models are inadequate because the classes are not linearly separable in raw pixel space. SOMs add unsupervised insight and support anomaly detection, while the MLP achieves the best recognition performance by learning non-linear feature hierarchies.

7. Conclusion

This project demonstrates a progressive path from biologically inspired, single-layer threshold models to modern multi-layer gradient-based learning. The Perceptron illustrates linear classification and the crucial concept of linear separability, while its XOR failure motivates the need for hidden layers. Adaline extends learning into differentiable optimization by minimizing MSE, making it a direct conceptual bridge to backpropagation. SOM offers a distinct unsupervised perspective, producing interpretable 2D maps of digit structure and enabling anomaly detection via quantization error. Finally, the NumPy-only MLP trained by backpropagation achieves strong MNIST performance (97.14% test accuracy), validating the representational power of multi-layer networks. Together, these paradigms form a unified system and enable a critical comparison of strengths, limitations, and suitability for pattern recognition tasks.
