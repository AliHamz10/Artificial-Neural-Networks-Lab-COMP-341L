Task 2.1 – Basic Hebbian Rule (Unstable) [5 Marks]
Implement the basic Hebbian learning rule and demonstrate its weight instability.
Required code structure (starter template):
import numpy as np
import matplotlib.pyplot as plt
def basic_hebbian(X, eta=0.01, n_epochs=50):
"""
Basic Hebbian learning rule: Δw = η * x * y
X: input data (n_samples x n_features)
"""
w = np.random.randn(X.shape[1]) * 0.01 # Initialize small random weights
weight_norms = []
for epoch in range(n_epochs):
for x in X:
y = np.dot(w, x) # Linear output
w += eta * y * x # Hebbian update (UNSTABLE)
weight_norms.append(np.linalg.norm(w))
return w, weight_norms
