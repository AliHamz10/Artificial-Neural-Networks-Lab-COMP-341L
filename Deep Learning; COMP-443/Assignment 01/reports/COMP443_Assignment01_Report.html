2. Dataset and Preprocessing

2.1 Fashion-MNIST overview

Fashion-MNIST is a 10-class image classification dataset with 28×28 grayscale images of clothing items (60k train, 10k test). Classes include T-shirt/top, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, and Ankle boot.

2.2 Splits and preprocessing

  • Download via tf.keras.datasets.fashion_mnist.
  • Normalise pixels from [0, 255] to [0, 1].
  • Split original training set into train/validation (80%/20%, fixed seed).
  • Add channel dimension (28×28×1) for CNNs; flatten to 784 features for classical models.

3. Classical Baselines

3.1 Logistic Regression

  • Multinomial logistic regression, lbfgs solver, L2 regularisation (C=1.0).
  • Trained on flattened features, evaluated on validation set.

Figure 1: Logistic Regression confusion matrix (validation).

3.2 Random Forest

  • RandomForestClassifier with 150 trees, max_depth=None, random_state=42.
  • Trained on flattened features; provides a stronger classical baseline.

Figure 2: Random Forest confusion matrix (validation).

4. Deep Learning Models

4.1 Simple CNN

Architecture: two Conv2D(32) layers with ReLU and same padding, MaxPooling2D, Flatten, Dense(128, ReLU), Dropout(0.3), Dense(10, softmax). Trained with Adam (lr=1e-3), batch size 128, up to 50 epochs with early stopping.

Figure 3: Simple CNN – loss and accuracy curves.

4.2 Deeper CNN

Architecture: two Conv2D(32) layers + MaxPool, then two Conv2D(64) layers + MaxPool, followed by Dense(256, ReLU), Dropout(0.4), Dense(10, softmax). Same training settings as Simple CNN.

Figure 4: Deeper CNN – loss and accuracy curves.

6. Discussion

Classical vs deep models: Classical models treat each pixel as an independent feature and ignore spatial structure. Random Forest improves over logistic regression by modelling non-linear interactions, but both are limited. CNNs exploit local patterns through convolutions and pooling, yielding better performance, particularly on confusing clothing categories.

Overfitting and regularisation: Dropout and early stopping prevent the CNNs from severely overfitting. Validation curves stabilise while training loss continues to decrease slowly.

Practical takeaway: On image data like Fashion-MNIST, CNNs are the natural choice, but classical models remain valuable baselines and may still be preferable when compute or explainability constraints dominate.

7. Conclusions

  • Random Forest outperforms logistic regression among classical methods (≈88.5% vs 85.7% accuracy).
  • Simple and deeper CNNs further improve accuracy (≈91.5–92.1%), demonstrating the advantage of deep models on image tasks.
  • Appropriate preprocessing, regularisation, and learning-rate choices are crucial for stable deep learning training.
